Welcome to Linux on Ariane!

You can use this rootfs folder to overlay the file system generated by buildroot.

Current OpenWiFi-related overlay additions:

- `usr/bin/openwifi_client.sh`: thin client-mode helper around `iw`, `wpa_supplicant`, `wpa_cli`, `wpa_passphrase`, and `udhcpc`
- `usr/bin/openwifi_ap`: AP mode helper (hostapd + udhcpd). Experimental — see `docs/todo/todo_openwifi_tx_auth_failure.md`
- `usr/bin/spi_ad9361_ping`: AD9361 SPI ping helper built from Theshire source
- `root/openwifi/user_space/*.sh`: ~35 OpenWiFi diagnostic/test scripts (regenerated from `util/regen_openwifi_scripts.sh`). Includes: CSMA bypass, RX/TX stats, AGC, RSSI, CSI fuzzing, raw IQ, monitor mode. See `docs/guide_debug_openwifi.md`
- `root/openwifi/user_space/openwifi_common.sh`: shared helper (sysfs detection, interface auto-detect)
- `root/openwifi/user_space/monitor_ch.sh`: theshire-specific override (iw instead of iwconfig)
- `root/openwifi/user_space/nic_back_to_normal.sh`: theshire-specific override (iw instead of iwconfig)
- `root/openwifi/arbitrary_iq_gen/`: IQ data files for raw TX testing
- `etc/openwifi/hostapd-openwifi.conf`: hostapd config for AP mode (5 GHz ch 36, WPA2-PSK)
- `etc/openwifi/udhcpd-openwifi.conf`: DHCP server config for AP mode
- `etc/init.d/S80openwifi`: boot-time WiFi init (regulatory domain, FIR filters)

For target-side usage of the WiFi client helper, see `docs/guide_test_wifi_client.md` in the parent Theshire repo.
For diagnostic tools reference, see `docs/guide_debug_openwifi.md`.
